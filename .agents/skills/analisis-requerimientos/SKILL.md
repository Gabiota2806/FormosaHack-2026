# 💡 Skill: Análisis de Requerimientos

## 🎯 Procedimiento Operativo
1. Recibir idea o requerimiento en bruto.
2. Inspeccionar modelos, routers y DB existente sin modificar nada.
3. Formular 2 a 4 preguntas clave de arquitectura.
4. Entregar bloque Markdown estructurado listo para Jira.
