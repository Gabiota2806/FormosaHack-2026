# 📋 Skill: Planificación en Jira Cloud

## 🎯 Procedimiento Operativo
1. Recibir especificación técnica (desde `/analisis` o texto del requerimiento).
2. Estructurar borrador:
   - Historia de Usuario BDD (Gherkin: Dado/Cuando/Entonces).
   - Subtareas técnicas con Story Points, archivos afectados y uso de Lucide React / Soft Delete.
3. Solicitar OK explícito de Gabriel en el chat.
4. Crear en Jira Cloud (`FH26`) vía API REST v3 (`.env.jira`).
